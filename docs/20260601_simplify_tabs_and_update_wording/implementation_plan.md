# UIタブ廃止およびプレビュー・コピペステーション文言変更計画

## 改修の背景と目的
新しくインラインの「ファイル/カメラから選択」ボタンを追加したことで、Streamlit標準の `st.file_uploader`（ファイル選択エリア）が完全に代替され、以前のタブUI（クリップボードペースト / 画像ファイルアップロード）は不要となりました。
そこで、より直感的に操作できるフラットな入力画面にするため、タブを廃止してペーストブリッジ（新UI）を直接露出させます。
また、ユーザー体験を高めるため、アライメント調整プレビューおよびコピペステーションの各見出し・説明テキストをよりシンプルでわかりやすい表現に統一します。

---

## ユーザー確認事項（要レビュー）
> [!NOTE]
> **タブ廃止後のUIイメージ**
> タブがなくなり、画面起動時にはダイレクトにペースト領域（貼り付けボタン、ファイル/カメラ選択ボタン、長押しエリア）のみが表示される、きわめて無駄のないApple Pro漆黒ミニマリズムに則った極上レイアウトになります。

## 提案する具体的な変更内容

### 1. タブUI（`st.tabs`）の廃止と一本化
- `app.py`（L273〜L328）にある `tab_paste, tab_upload = st.tabs(...)` を除去します。
- `tab_upload`（Streamlit標準アップローダー）のブロックを完全に削除します。
- 旧 `tab_paste` の中身（説明テキスト、`paste_bridge` の読み込みおよび受信処理）を、親のカード（`<div class="apple-card">`）の中に直接フラットに配置します。

### 2. プレビューエリアおよび説明テキストの文言変更
- 見出し（L333付近）を `st.subheader("読取りエリア調整プレビュー")` に変更します。
- 説明文（L334付近）を `st.write("右側のスライダーを操作して、枠が数値エリアに重なるよう調整してください。")` に簡素化変更します。

### 3. コピペステーションの文言変更
- 見出し（L728付近）を `st.subheader("コピペステーション")` に変更します。
