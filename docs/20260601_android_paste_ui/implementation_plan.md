# Android・モバイル親和性の高い画像貼り付けUIへの変更計画

## 解決したい課題と背景
既存の `paste_bridge` コンポーネントは、パソコン環境における `Ctrl + V`（キーボードショートカット）やドラッグ＆ドロップ操作を前提として設計されています。
そのため、キーボードがなく、画面タップが主体となるAndroidやiOSなどのモバイル端末においては、以下のような課題が発生します。
1. `Ctrl + V` が送信できない。
2. 通常の `div` 要素（`tabindex="0"` のみ）ではモバイルブラウザで長押ししても「貼り付け」ポップアップが出現しにくい。
3. モバイル端末のクリップボードやカメラ、最近のスクリーンショットを直接シームレスに取り込む手段がない。

これらを解消し、デスクトップ・モバイルの双方で極めて高い操作性を発揮する、Apple Pro漆黒ミニマリズムを踏襲したハイブリッドペーストUIへリニューアルします。

---

## ユーザー確認事項（要レビュー）
> [!IMPORTANT]
> **HTTPS環境とClipboard APIの制約について**
> 「クリップボードから直接貼り付け」ボタンは、ブラウザのセキュリティ制限（Clipboard API）に依存します。
> localhost環境、またはセキュアな接続（HTTPS）下でのみブラウザはこのAPIの利用を許可します。
> 非セキュア環境（通常のHTTPによるリモートアクセス）の場合は自動的にボタンが無効化または警告表示となりますが、その場合でも以下の「フォールバック機能（長押しペースト、ファイル選択）」が動作するよう設計します。

---

## 提案する具体的な改善策

`src/paste_bridge/index.html` を大幅に拡張し、以下の3つのペーストアプローチを1つの美しいUIの中に統合します。

```
+-------------------------------------------------------------+
|                                                             |
|   [ 📋 クリップボードから貼り付け ]  [ 📷 ファイル/カメラから選択 ]   |
|                                                             |
|   +-----------------------------------------------------+   |
|   | ここをタップ（長押し）して貼り付け                   |   |
|   +-----------------------------------------------------+   |
|                                                             |
+-------------------------------------------------------------+
```

### 1. 【極上体験】Clipboard APIによるワンタップ貼り付け
- **実装内容**: `navigator.clipboard.read()` を実行する「貼り付け」ボタンを設置。
- **挙動**: タップするだけでブラウザのクリップボード権限確認が表示され、許可すると瞬時に画像データが読み込まれます。

### 2. 【モバイル最適】インラインファイル/カメラアップローダー
- **実装内容**: 隠し `<input type="file" accept="image/*">` を配置し、「ファイル/カメラから選択」ボタンで起動。
- **挙動**: Androidの「ファイル選択」画面が開き、最近保存したスクリーンショットを2タップで選択できるほか、その場でカメラを起動して撮影することも可能です。

### 3. 【強固な互換性】`contenteditable` 属性を用いた長押しペーストエリア
- **実装内容**: `contenteditable="true"` を設定したテキスト入力エリアを設置。
- **挙動**: スマホでタップするとソフトキーボードが立ち上がり、キーボード上の「クリップボード内の画像」を選択して貼り付けたり、長押しでOS標準の「貼り付け」メニューから画像を直接ペーストできます。
