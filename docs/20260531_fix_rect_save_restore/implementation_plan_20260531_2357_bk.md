# 実装計画書：有効項目同期バグ根本解決 ＆ コピペステーション不要項目非表示化 ＆ 無限ロード根絶

チェックON/OFF状態がJSONに保存・復元されない不具合を「逆流同期防止ガード」によって完璧に解決し、さらに「コピペステーション」において、読み取り無効にした項目や値が空の項目をヘッダー・データから完全に除外するための実装計画です。

---

## 🔍 原因分析

### 1. 有効項目ON/OFFがJSONに保存されない真の物理の原因（同期の「逆流上書き戻り」の罠）
- **状態同期における「ガードの欠落」**:
  ユーザーがチェックボックスをOFFにした際、JS側では `state.activeItems` から正常に対象項目が除外され、150msのデバウンスの後に `update_state` として Python に送られます。
  スライダー位置やその他の座標データの同期には、親（Python）から送られてくる古いメッセージ（まだ変更が反映されていないデータ）によってローカル最新状態が上書きされないようにするためのキャッシュガード（`lastSentState` ガード）が実装されていました。しかし、**`active_items` に対するキャッシュガードが完全に欠落していました。**
- **逆流上書き戻りの発生**:
  チェックを外して `sendMessage("update_state")` が送信されてから Python 側が処理を完了して再実行するまでの極めて短いタイムラグの間に、Python 側から送られてくる古い状態（まだ全ON of 24項目の状態）の `streamlit:render` 逆同期メッセージを受信してしまっていました。
  このときJS側は、Python側の古い状態を「最新 of 逆同期データ」と誤認し、**JS側のローカル状態（OFFが反映された状態）を「すべてON」に勝手に上書きして引き戻していました。**
  この「同期の逆流上書き戻り」により、JSONに保存しようとした時点では常に全ONの元の状態に勝手に戻ってしまっていました。

### 2. コピペステーションに無効項目や空項目が出力される原因
- **無差別なTSV出力仕様**:
  従来の「超速コピペステーション（縦型カルテ用、スプレッドシート用）」では、チェックON/OFF状態（`active_items`）やデータの有無に関わらず、全てのOCR読み取り可能カラムヘッダーおよびデータ行の内容（空値を含む）を一律でTSV出力する仕様になっていました。そのため、ユーザーが無効化した項目や、解析値が空の項目も無条件にヘッダー名や項目名だけが表示され、貼り付け時の利便性を損ねていました。

---

## 🛠️ 対策案（提案内容）

「逆流同期防止ガード」の適用によって同期の不具合を完璧に根本解決し、コピペステーションの動的フィルタリングによってプレミアムな極上のUXを実現します。

### 1. `active_items` への `lastSentState` 逆流上書き防止ガードの徹底適用
- JS側の `lastSentState` キャッシュに `activeItems` 配列を追加し、`streamlit:render` 受信時には、直近で送信した最新の状態と比較して古いメッセージからの逆同期上書きを完全に無視（ガード）するロジックを実装します。
  - **JS側のキャッシュ登録**:
    ```javascript
    lastSentState = {
        ...,
        activeItems: [...state.activeItems]
    };
    ```
  - **逆流ガードの適用**:
    ```javascript
    const isOld = lastSentState && lastSentState.activeItems && (
        args.active_items.length !== lastSentState.activeItems.length ||
        !args.active_items.every(x => lastSentState.activeItems.includes(x))
    );
    ```
- これにより、チェックON/OFF状態が再描画や再起動を挟んでも**100%完璧に維持**され、Python側のセッション状態に正しいON/OFF配列が同期され、JSON保存・復元時にも一寸の狂いもなく完全復旧されるようになります。

### 2. コピペステーションでの「無効・空項目」の動的フィルタリングの実装
`app.py` において、TSVデータを構築する処理に以下のフィルタリングを適用します。
- **縦型カルテ入力用（縦展開TSV）**: 
  各行を出力する際、項目名が `st.session_state.active_items` に含まれており、かつ、その値が空文字列 `""`（または空白）でない場合のみ、項目名と値をセットで出力します。
- **スプレッドシート行追加用（横展開TSV）**: 
  出力するカラムヘッダーおよびデータ列について、項目が `st.session_state.active_items` に含まれており、かつ、**今回の解析結果データフレームの全行の中で少なくとも1行で有効な値が存在する項目**のみを対象とします。これによりセルの位置ズレを完璧に防ぎつつ、不要なカラムヘッダーやデータ列を美しく完全に除外します。
