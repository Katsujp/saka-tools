# 実装計画書：コピペ展開形式の調整 ＆ コピペステーションクリアボタン追加 ＆ アプリタイトル・説明文の日本語化

コピペステーションの「項目名を出力する」トグルがOFFの際に出力形式を極限までシンプルに値だけにクレンジングし、操作性向上のための「コピペステーションをクリア」ボタンの追加、およびアプリケーションタイトル・説明文の分かりやすい日本語名称への書き換えを行うための実装計画です。

---

## 🔍 要件分析と機能設計

### 1. 「項目名を出力する」がOFFの際、画像名区切り線（デリミタ）も非表示にする
- **現状の問題点**: 
  現在、縦展開TSVにおいて「項目名を出力する」がOFFであっても、先頭に選手画像名の区切り線（例：`--- 【画像: Clipboard_1780239617】 ---`）が常に出力されていました。スプレッドシートや管理表への完全な「値のみ」の流し込み（バルクコピペ）の障害となるため、トグルOFFの際はこの区切り線も非表示にします。
- **設計**:
  縦展開TSVの構築処理において、`show_headers` トグルが `True`（項目名を出力する）のときのみ、画像名区切り線 `--- 【画像: ...】 ---` を出力するようにロジックを修正します。

### 2. 「コピペステーションをクリア」ボタンの新設
- **設計**:
  「解析結果テーブルを空にする」ボタンの右隣（かつ「展開ボタン」の左隣）に、新しく **「コピペステーションをクリア」** ボタン（`st.button`）を配置します。
  ボタンレイアウトは3者均等のスッキリとした配置（`[1, 1, 1, 1]` のカラム分割で左側はスペーサー）とします。
  ```python
  col_empty_spacer, col_clear_res, col_clear_copy, col_export = st.columns([1, 1, 1, 1])
  ```
- **効果**:
  解析テーブルのレコードを残したまま、コピペステーションの表示領域だけを空（初期の展開待ち状態）にリセットしてクリーンにすることができます。

### 3. アプリケーションタイトルと説明文の日本語化
- **設計**: 
  `app.py` のメインエリアヘッダー部分に表示されている英語タイトルおよび英語まじりの説明文を、より親しみやすく的確な日本語テキストに書き換えます。
  - **メインタイトル**: `Parameter Precision Reader` 
    👉 **変更後**: `サカつく2026 パラメータOCRリーダー v0.1`
  - **サブタイトル**: `高精度画像解析と、極めてスムーズなアライメント調整を提供するパラメータ抽出システム。`
    👉 **変更後**: `選手のパラメータタブの中身を読み取るツール`
