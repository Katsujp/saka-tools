# 実装計画書：コピペステーション表示制御 ＆ 動的行選択・トグル切り替え機能の実装

解析結果のコピペステーション（TSV展開エリア）において、明示的な「展開実行ボタン」の作成、編集テーブル上で選択（チェック）した行のみの抽出、および項目名の有無を切り替えられるチェックボックスを搭載するための実装計画です。

---

## 🔍 要件分析と機能設計

### 1. 編集テーブル上での動的行選択（チェックボックスの搭載）
- **設計**: `st.data_editor` に表示されるデータフレームの左端に、行選択用の論理値カラム `"選択"` をデフォルトで `True`（全選択状態）の状態で挿入します。
  ```python
  df_ordered.insert(0, "選択", True)
  ```
- **効果**: ユーザーはテーブル上でコピーしたい任意の行のみをチェックボックスで動的に選択できます。また、テーブル上のヘッダーをクリックして並び替えられた順序（順序情報）も維持された状態でデータを処理します。

### 2. 「コピペステーションに展開する」ボタンの追加
- **設計**: プレビューHUDの「解析結果テーブルを空にする」ボタンの右隣に、新しく **「コピペステーションに展開する」** ボタンを配置します。
  ```python
  col_empty_spacer, col_clear_res, col_export = st.columns([2, 1, 1])
  ```
- **効果**: ユーザーがこのボタンを押したタイミングで、初めてチェックの入っている行のみが抽出され、TSVデータとしてコピペステーションにロード（展開）されます。

### 3. 「項目名を出力する」チェックボックスの追加
- **設計**: 新規追加する展開ボタンの下部（カード内）に、**「項目名を出力する」** トグルチェックボックス（`st.checkbox`、デフォルトは `False`/OFF）を配置します。
- **効果**: 
  - **ONの場合**: コピペステーション（横展開・縦展開TSV）に展開する際、項目名（ヘッダー名 / カラム名）を付与して出力します。
  - **OFFの場合**: 項目名は一切出力せず、テーブルの並び順通りに**値（データ）のみをタブ区切りで展開**します。

### 4. コピペステーション用のセッションキャッシュの導入
- **設計**: 画面の再描画によってコピペステーションがクリアされないよう、展開されたTSV文字列を `st.session_state.tsv_horizontal` および `st.session_state.tsv_vertical` に保存します。
- **効果**: ボタンが押されるまでコピペステーションは空の状態で待機し、ボタンが押されると成功メッセージとともにデータが永続展開され、コピーが即座に行えるようになります。

## Verification Plan（検証計画）

### 1. 手動による機能動作検証
1. **初期ロード時のコピペステーション表示の確認**:
   - アプリケーション起動時、コピペステーション領域に「データが展開されていません。上のボタンを押してください。」と表示されていることを確認します。
2. **テーブル上での部分選択と並び替えテスト**:
   - 解析結果テーブルをロードし、特定の行の「選択」チェックボックスをOFFにします。
   - 残りのチェックONの行について、任意のヘッダーをクリックして並び替え（ソート）を行います。
3. **「項目名を出力する」トグルOFF（デフォルト）での展開テスト**:
   - トグルがOFFであることを確認し、「コピペステーションに展開する」ボタンをクリックします。
   - コピペステーションに出力されたTSVを確認し、**項目名（「元画像名」「決定力」など）が一切出力されず、テーブルの並び順通りに選択行の値のみがタブ区切りで出力されていること**を確認します。
4. **「項目名を出力する」トグルONでの展開テスト**:
   - トグルをONに切り替え、「コピペステーションに展開する」ボタンをクリックします。
   - コピペステーションを確認し、**横展開では最上行にヘッダー（項目名）が挿入され、縦展開では「項目名 [Tab] 値」の形式で正しく出力されていること**を確認します。また、チェックを外した行のデータが一切含まれていないことを目視します。
