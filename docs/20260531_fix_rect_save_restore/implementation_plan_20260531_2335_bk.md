# 実装計画書：アライメント矩形位置情報の保存・復元修正 ＆ 切り替え式リアルタイム同期ログ実装

スライダー調整値の保存・復元不具合の根本解決（イベントデリゲーション導入）、キーボード操作時の画面グレーアウト解消に加え、**同期プロセスを透明化して動作を完全に実証できる「ON/OFF切り替え式のリアルタイム同期ログ」**を実装するための計画です。

---

## 🔍 原因分析

### 1. 保存・復元が機能しない真の物理の原因
- **イベントリスナーの剥落**: アコーディオン内の個別スライダーは `setupAlignmentUI()` によって `innerHTML` を使い動的に再生成されます。この `innerHTML` の代入により、ページロード時に登録されていた `change` イベントリスナー（Pythonへの同期トリガー）が**完全に剥がれ落ちて消失**していました。そのため、スライダーをいくら操作しても値が親に送信されず、JSONが初期値 `0` のままになっていました。

### 2. キーボード連打時に画面がグレーアウトする原因
- **Streamlit デフォルトのロード中オーバーレイ**: キーボード微調整を高速連打すると、連打のたびに `change` イベントが発生し、Python 側の再実行（Running）が極めて短い間隔で連続してトリガーされます。
  Streamlit の仕様として、実行中は画面全体の不透明度を一時的に半透明（`opacity: 0.2` 等）にする半透明オーバーレイが適用されます。連打するとこのオーバーレイが高速でON/OFFされるため、画面が激しく点滅して極めて見づらくなっていました。

---

## 🛠️ 対策案（提案内容）

バグ治療、グレーアウト解消、および透明性の高い可視化デバッグログの実装を同時に行い、プレミアムな極上の操作感（UX）と完璧な信頼性を実現します。

### 1. 「イベントデリゲーション」の導入（バグの根本解決）
- 個別のスライダーに個別にリスナーを貼るのをやめ、`document.body.addEventListener("change", ...)` によるイベントデリゲーションを導入します。
  アコーディオンが何度動的に再生成されようとも、親である `body` 要素が一括してスライダーの `change` イベントを100%確実にキャッチして `notifyStateChange()` を実行します。これでリスナー剥がれのバグを完全根絶します。
- 静的HTMLに記述されている4つの全体アライメントスライダー（全体X/Yシフト、全体X/Yスケール）に、明示的に `onchange="notifyStateChange()"` を追記し、2重の防護策とします。

### 2. 「150ms デバウンス同期」と「CSSによるオーバーレイ無無効化」（グレーアウト解消）
- JS側の `notifyStateChange` に **150ms のデバウンス（遅延同期）** を組み込みます。
  キーボードの矢印キーを押し続けたり連打している間は送信を保留し、連打の手が止まった瞬間に初めて最新データを送信します。
- `app.py` のスタイリング部分に、再実行中に適用される不透明度の変化（`opacity` 減少）を無効化するCSS（`opacity: 1 !important`）を追加します。これにより、万が一同期が走った際でも画面は一切グレーアウトせず、常に完全にクッキリと表示され続けます。

### 3. 表示/非表示が切り替え可能な「リアルタイム同期ログ」の実装（追加要件）
- **同期ログの切り替えスイッチ**: `app.py` のプレビューHUD下に、**「リアルタイム同期ログを表示」トグルチェックボックス**（`st.checkbox`）を配置します。デフォルトは非表示にし、ユーザーが必要に応じて表示できるようにします。
- **ログの可視化**: トグルチェックボックスがON of 時、その下に最新10件程度の同期ログが流れるコンソールプレート（`st.code`）を表示します。OFFの時はクリーンなデザインを維持するため非表示にします。
- **JS側のログ送信**: スライダーが変更されて `notifyStateChange()` が実行される際、変更された項目と値の情報を文字列として `debug_log` キーにマージして親（Streamlit）に送信します。
  例：`debug_log: "JS: '走力' Individual Offset Y shifted to 4px"`
- **Python側のログ蓄積**: `app.py` で `update_state` を受信した際、渡された `debug_log` を取得し、タイムスタンプを付与して `st.session_state.sync_logs` リストに蓄積します。その後、Python側でのセッション更新成功ログも追記します。
  例：`"[21:20:05] PY: st.session_state.individual_offsets['走力'] updated to [0, 4]"`
