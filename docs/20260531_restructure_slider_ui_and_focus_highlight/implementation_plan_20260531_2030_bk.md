# 実装計画：UIスライダーのグループ再構成およびキーボードフォーカス強調表示の実装

本ドキュメントは、アライメント調整画面（Canvas HUD）の右側コントロールパネルにおいて、従来の「グループ一括調整」と「個別調整」の分離構成を廃止し、各グループ（カテゴリ）ごとに「グループ全体調整」と「個別調整」を美しく統合する再編成を行い、かつキーボード操作を快適にするフォーカス強調表示を実装するための計画書です。

## 🛠️ 提案する具体的な変更設計 (承認後に実施)

### 1. 右側コントロールパネルのスライダー再編成 (グループ別完全統合)
従来の「グループ一括調整（案A）」と「項目別個別微調整（案B）」の2大セクションに分かれていたアコーディオンを完全に廃止し、**各カテゴリ（グループ）ごとに統合されたアコーディオン/カード**に集約します。

* **カテゴリ別の構成定義**:
  - **「総合力」アコーディオン**:
    - グループ全体の調整は不要なため、個別項目 **「総合力」** のスライダー（X/Yシフト、X/Yスケール）のみを配置します。
  - **「カテゴリー数値」アコーディオン**:
    - **カテゴリー数値 (全体)** の調整スライダー（X/Yシフト、X/Yスケール）を最上部に配置。
    - その下に、属する個別項目（**SHO数値, PAS数値, DRB数値, DEF数値, PHY数値, SPD数値**）の個別微調整スライダーを配置。
  - **「SHO」アコーディオン**:
    - **SHO (全体)** の調整スライダーを最上部に配置。
    - その下に、属する個別項目（**決定力, キック力, 冷静さ**）の個別スライダーを配置。
  - **以下、各グループ（PAS, DRB, DEF, PHY, SPD）も同様にアコーディオン内に全体調整と個別調整をまとめて配置**します。

* **JS側でのUI動的生成ロジックの刷新 (`src/fitting_hud/index.html`)**:
  HTML側にはアコーディオンの親コンテナ `<div id="alignmentContainer"></div>` のみを定義し、JavaScript側で `GROUPS` オブジェクトに基づいて、カテゴリ別のアコーディオンとスライダー群を動的に一括構築する美しい設計に書き換えます。
  個別スライダーは、その項目が「読み取り有効項目（チェックボックス）」でONになっている場合のみ動的に表示されます。

### 2. キーボード操作のためのフォーカス強調スタイリングの実装
* **CSSによるフォーカス強調 (`src/fitting_hud/index.html` の Style)**:
  `Tab` キーやクリックによって現在フォーカスが当たっているスライダー（`input[type="range"]`）が直感的に識別できるよう、洗練されたApple Pro Blueカラーを用いた強調スタイリングを追加します。
  ```css
  /* スライダーフォーカス時のシャープな強調表示 */
  .apple-slider:focus {
      background: var(--accent-color) !important;
      outline: none;
  }
  
  .apple-slider:focus::-webkit-slider-thumb {
      background: #359aff !important; /* フォーカス時はつまみをより鮮やかな青に */
      box-shadow: 0 0 8px rgba(10, 132, 255, 0.8), 0 2px 6px rgba(0, 0, 0, 0.4);
      transform: scale(1.2);
  }
  ```

## 📊 検証計画 (Verification Plan)

### 手動・UI/UX検証
1. `python -m py_compile app.py` による構文チェックを実行。
2. アプリケーションをリロードし、右側コントロールパネルの構成を確認。
3. **「総合力」アコーディオンを開き、中に「総合力」のみの調整スライダーが存在することを確認。**
4. **「SHO」などのカテゴリのアコーディオンを開き、最上部に「SHO (全体)」、その下に「決定力」「キック力」「冷静さ」の個別スライダーがまとまって配置されていることを確認。**
5. チェックボックスで「決定力」をOFFにした際、SHOアコーディオン内の「決定力」個別スライダーのみが即座に非表示になることを確認。
6. `Tab` キーを押してスライダー間をフォーカス移動した際、現在選択されているスライダーの背景やつまみの色が**美しい青色にビビッドに変化し、キーボード（矢印キー）でどのパラメータが動くかが完璧に視認できること**を確認。
