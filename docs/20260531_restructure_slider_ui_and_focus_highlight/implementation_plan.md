# UIスライダーのグループ再構成およびキーボードフォーカス強調表示の実装計画 (アコーディオン全展開対応)

本ドキュメントは、アライメント調整画面（Canvas HUD）の右側コントロールパネルにおいて、従来の「グループ一括調整（案A）」と「項目別個別微調整（案B）」の物理的な分離構成を廃止し、各カテゴリ（グループ）ごとに「全体調整」と「個別調整」を美しく統合し、さらにキーボード操作を快適にするフォーカス強調表示およびアコーディオン全展開を実装するための計画書です。

---

## 原因・現状の課題

1. **操作の行き来が発生するUI構造**: 
   これまでは「グループ一括調整」と「個別微調整」が離れた別々のアコーディオンに配置されていたため、同じカテゴリー（例：SHO数値と決定力）を調整する際に、ユーザーがアコーディオン間を上下に行き来してスライダーを操作する必要があり、操作効率が低下していました。
2. **キーボード操作時のフォーカス視認性の不足**:
   キーボード（`Tab`キーなど）でスライダーにフォーカスを当てて微調整（左右の矢印キーなど）する際、現在どのスライダーが選択状態にあるのかが視覚的に非常に分かりづらく、直感的な操作が困難でした。
3. **キーボード移動時のアコーディオン閉鎖による不都合 (今回の追加要望)**:
   デフォルトで一部のアコーディオンが閉じている場合、`Tab` キーによるフォーカスの移動時に、閉じているアコーディオン内のスライダーにフォーカスが遷移せず、キーボードのみでの全体的な操作性（パラメータ移動）を著しく損ねる原因となります。そのため、初期状態で全てのアコーディオンを展開状態とする必要があります。

---

## ユーザーレビューが必要な内容

> [!NOTE]
> - 全てのアコーディオン（総合力、カテゴリー数値、SHO、PAS、DRB、DEF、PHY、SPD）は、初期状態（画面ロード時）で**完全に展開（オープン）された状態**となります。これにより、キーボードの `Tab` キーを押すだけで、上から下まで一切遮られることなくスムーズにフォーカスが遷移します。
> - 各アコーディオンは必要に応じてユーザーがクリックして閉じることも可能です。

## 提案する具体的な変更設計

### 1. 右側コントロールパネルのスライダー再構成 (グループ別完全統合)
従来の「グループ一括調整」と「項目別個別微調整」の2大アコーディオンを廃止し、**各カテゴリ（グループ）ごとに統合されたアコーディオン**に集約します。

* **カテゴリ別の構成定義**:
  - **「総合力」アコーディオン (`overall`)**:
    - グループ全体の調整は不要なため、個別項目 **「総合力」** のスライダー（X/Yシフト、X/Yスケール）のみを配置します。
  - **「カテゴリー数値」アコーディオン (`category`)**:
    - **カテゴリー数値 (全体)** の調整スライダー（X/Yシフト、X/Yスケール）を最上部に配置。
    - その下に、属する個別項目（**SHO数値, PAS数値, DRB数値, DEF数値, PHY数値, SPD数値**）の個別微調整スライダーを配置。
  - **「SHO」アコーディオン (`sho`)**:
    - **SHO (全体)** の調整スライダーを最上部に配置。
    - その下に、属する個別項目（**決定力, キック力, 冷静さ**）の個別微調整スライダーを配置。
  - **「PAS」アコーディオン (`pas`)**:
    - **PAS (全体)** の調整スライダーを最上部に配置。
    - その下に、属する個別項目（**ショートパス, ロングパス, キック精度**）の個別微調整スライダーを配置。
  - **「DRB」アコーディオン (`drb`)**:
    - **DRB (全体)** の調整スライダーを最上部に配置。
    - その下に、属する個別項目（**突破力, キープ力, ボールタッチ**）の個別微調整スライダーを配置。
  - **「DEF」アコーディオン (`def`)**:
    - **DEF (全体)** の調整スライダーを最上部に配置。
    - その下に、属する個別項目（**タックル/セービング, パスカット/反応速度, マーク/1対1**）の個別微調整スライダーを配置。※GK時はGK用ラベルに動的変更。
  - **「PHY」アコーディオン (`phy`)**:
    - **PHY (全体)** の調整スライダーを最上部に配置。
    - その下に、属する個別項目（**ジャンプ, コンタクト, スタミナ**）の個別微調整スライダーを配置。
  - **「SPD」アコーディオン (`spd`)**:
    - **SPD (全体)** の調整スライダーを最上部に配置。
    - その下に、属する個別項目（**走力, 敏捷性**）の個別微調整スライダーを配置。

* **JavaScript側でのアコーディオン全展開の適用 (`src/fitting_hud/index.html`)**:
  - JavaScriptのアコーディオン開閉状態キャッシュ `accordionStates` の初期値をすべてのカテゴリーで `true` に設定します。
  - これにより、初回レンダリング時にすべてのスライダーが配置されたコンテナが表示され、Tabキーのフォーカス移動がスムーズになります。

### 2. キーボード操作のためのフォーカス強調スタイリングの実装
* **CSSによるフォーカス強調 (`src/fitting_hud/index.html` の Style)**:
  `Tab` キーやクリックによって現在フォーカスが当たっているスライダー（`input[type="range"]`）が直感的に識別できるよう、洗練されたApple Pro Blueカラーを用いた強調スタイリングを追加します。
  ```css
  /* スライダーフォーカス時のシャープな強調表示 */
  .apple-slider:focus {
      background: var(--accent-color) !important;
      outline: none;
  }
  
  .apple-slider:focus::-webkit-slider-thumb {
      background: #359aff !important; /* フォーカス時はつまみをより鮮やかな青に */
      box-shadow: 0 0 8px rgba(10, 132, 255, 0.8), 0 2px 6px rgba(0, 0, 0, 0.4);
      transform: scale(1.2);
  }
  ```
