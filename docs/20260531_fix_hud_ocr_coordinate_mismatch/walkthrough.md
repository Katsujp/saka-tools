# 修正内容の確認 (Walkthrough)：表示座標とOCR座標の不整合（トリミング有無）の解消

本ドキュメントは、ご承認いただいた実装計画に沿って実施した、アライメント調整プレビューの青枠位置と、OCR実行時の切り出し位置（ROI）との間の決定的な座標乖離バグの修正内容と検証結果をまとめた完了報告書です。

---

## 🛠️ 実施した修正内容

### 1. フロントとバックの画像前提（描画領域）の100%完全統合
プレビュー画面の座標と、OCR実行時の画像切り出し座標が完全に一致しない根本原因であった「ウィンドウ枠・タイトルバーのトリミング有無の乖離」を完全に解消しました。

*   **`get_normalized_image_base64` 関数の実装と統合**:
    `app.py` において、`fitting_hud` にプレビュー画像（Base64形式）を引き渡す際、元の生画像をそのまま渡すのではなく、**「OCRエンジンの自動境界スキャン（トリミング）と1920x1080正規化を事前に施した後の画像」** を生成して引き渡すように修正しました。
*   これにより、アライメント調整を行う背景画像自体から Windows の余分なウィンドウタイトルバーや黒枠などが自動的に消去され、**「OCRエンジンが実際にスキャンする画像」と1pxの狂いもなく100%完全に一致する**ように設計を統一しました。
