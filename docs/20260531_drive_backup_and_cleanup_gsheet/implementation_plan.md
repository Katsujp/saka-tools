# 実装計画：Googleスプレッドシート設定の廃止およびGoogleドライブ矩形位置情報バックアップ機能の実装 (シームレスOAuth2・起動時ダイアログ対応)

本ドキュメントは、不要となった「Googleスプレッドシート/Excel書き出し機能および設定」をUIから完全に排除してUIを整理し、代わりにユーザーが長時間の調整で作り上げた「矩形位置情報（ROIパラメータ）」をGoogle Drive上の「Saka-tools_backup.json」としてセキュアに保存・復元できるシームレスなOAuth2連携機能、および起動時の復元確認ダイアログを実装するための計画書です。

---

## 現状の課題・背景 (原因)

1. **不要機能の整理**:
   スプレッドシート設定やExcelエクスポート機能は現在不要となっており、代わりにコピペ用のTSVテキスト（超速コピペステーション）や表の直接編集機能があれば十分であるため、サイドバーの設定フォームや下部の書き出しボタン群が画面を煩雑にさせている原因となっていました。
2. **矩形調整データ消失の懸念**:
   せっかく調整した各パラメータの矩形枠座標が、アプリの再起動やブラウザの更新によってリセットされてしまうため、設定値をクラウド上に安全に永続化し、いつでも一発で復元できるバックアップ機能が求められていました。
3. **ユーザー利便性とプライバシーへの配慮 (今回の追加要望)**:
   - **OAuthの秘密JSONアップロードの廃止**: ユーザー自身に `client_secrets.json` などの機密資格情報ファイルを作成・アップロードさせるのは非常にハードルが高いため、デスクトップ用のクライアントIDとシークレットをアプリケーション内にあらかじめ組み込み（内蔵）、ボタンを押すだけでGoogleの公式認証画面が自動ポップアップする形式にします。
   - **Googleドライブ未使用者への配慮**: 起動時に勝手にドライブ接続を試みたりエラーを起こしたりしないよう、ツールを開いた初回時に「Google Driveから設定情報を復元するかどうか」を尋ねる親切な確認ダイアログを表示する仕様にします。

## 提案する具体的な変更設計

### 1. スプレッドシート保存およびExcelエクスポート機能の完全廃止
- **サイドバー設定の削除**: 
  - `app.py` からサイドバー内の「Googleスプレッドシート設定」セクション全体を完全に削除し、サイドバーをすっきり整理します。
- **エクスポートセクションの整理**: 
  - 画面最下部の「5. バックアップ保存と出力」カードを廃止します。
  - スプレッドシートへの追記処理、SakatsukuGSheetClient関連コード、Excelダウンロードボタンを完全に削除します。
  - 「解析データを空にする（データテーブルのクリア）」ボタンのみを、解析結果テーブルのすぐ下などの適切な位置にシンプルに再配置します。
  - 表のプレビュー、ダブルクリック編集、TSVコピペ用コード（横展開・縦展開）はそのまま完全に残します。

### 2. アプリ起動時の「復元確認ダイアログ」の実装
- **確認フラグの導入**: `st.session_state` に `drive_restore_checked` フラグを導入し、セッション開始時にダイアログの表示判定を行います。
- **復元確認ダイアログの表示**:
  - `st.dialog`（または互換性の高いインライン確認コンポーネント）を用いて、起動時に「以前調整した矩形位置情報をGoogle Driveから復元しますか？」というダイアログを表示します。
  - 「復元する（Googleアカウントに接続して復元）」が選ばれた場合は、自動的にOAuth2フローを実行します。
  - 「復元しない（デフォルトのまま起動）」が選ばれた場合は、ダイアログを閉じ、デフォルト設定のまま画面が立ち上がります。一度回答すれば、そのセッション中は再表示されません。

### 3. Google Drive矩形位置情報バックアップ機能の実装 (シームレスOAuth2)
- **依存ライブラリの追加**: 
  - `pip install google-api-python-client google-auth-oauthlib google-auth-httplib2` を実行して依存環境を整備します。
- **デスクトップOAuth2資格情報の内蔵**:
  - デスクトップアプリケーション専用の `CLIENT_CONFIG`（クライアントID、シークレット）を Python 側に組み込みます。ユーザー側でのJSONファイルアップロードの手間を一切排除します。
- **ポップアップ認証フローの実装**:
  - 「Googleアカウントに保存」またはダイアログから「復元する」が押された際、`InstalledAppFlow.from_client_config` と `flow.run_local_server(port=0)` によって自動的にブラウザにGoogleのアカウント選択および認証画面がポップアップ（新しいタブでオープン）するようにします。
  - 認証が完了すると、取得したセキュアなアクセストークンを `token_drive.json` として `C:\Users\katsu\.gemini\antigravity\scratch\sakatsuku_2026\token_drive.json` に安全にキャッシュ保存します。
  - 2回目以降は、このキャッシュを利用して自動的にバックグラウンドでトークンをリフレッシュし、ユーザーに再度ブラウザを開かせることなく一瞬で通信を完了させます。
  - スコープには、アプリ専用の書き込み領域に限定し、セキュリティが極めて高い `https://www.googleapis.com/auth/drive.file` を適用します。
- **保存・復元UIの配置**:
  - `fitting_hud` （アライメントプレビュー）のすぐ下に、「Googleアカウントに保存」「Googleアカウントから復元」ボタンをビジュアルに優れたApple Proデザインで2カラム配置します。
- **保存処理 (Save)**:
  - Google Drive上に「Saka-tools_backup.json」が存在するか検索。
  - 存在する場合は上書き更新（Update）、存在しない場合は新規作成（Create）をGoogle Drive APIを介して実行。
  - 保存対象：
    - `global_scale_x`, `global_scale_y`, `global_offset_x`, `global_offset_y`
    - `group_offsets`, `group_scales`
    - `individual_offsets`, `individual_scales`
    - `is_gk`, `active_items`
- **復元処理 (Restore)**:
  - ドライブから「Saka-tools_backup.json」を読み込んでデコード。
  - Pythonの `st.session_state` のアライメント値を一括上書き。
  - `st.rerun()` を実行して逆同期ハンドラを経由し、フロントエンドのCanvas HUDスライダーや座標枠に復元データを即時同期します。
