# 【サカつく2026】パラメータ画面画像からの数値自動抽出ツール開発計画

本計画は、ユーザーが『プロサッカークラブをつくろう！2026』の育成モードで選手のパラメータをスプレッドシートに手動転記する際のボトルネックを解消するため、画像解析（OCR）を用いてパラメータ画面から数値を自動的に読み取り、スプレッドシート形式で出力するシステムを構築する計画です。

## 原因（手動転記のボトルネック）

ゲーム内の選手育成において、複数の選手のパラメータをスプレッドシートに記録する際、**「画面を目視しながら手動で数値を転記する」**作業が発生しており、以下の課題が存在します。
1. **多大な時間と手間**: 1人の選手につき「総合力」「メイン6項目（数値＋ランク）」「個別17項目（決定力、ショートパス等）」および「選手名」「ポジション」など多くの項目があり、これらを手動入力するのは非常に時間がかかる。
2. **誤入力のリスク**: 目視転記では、数字の打ち間違いや項目のズレなどのヒューマンエラーが発生しやすい。
3. **育成効率の低下**: 育成シミュレーションを行う前段階 of データ入力作業が障壁となり、ゲームのプレイングに集中できない。

## ユーザー確認が必要な事項（ご質問）

開発を進めるにあたり、より使いやすく最適なツールとするため、以下の点についてご確認をお願いいたします。

> [!IMPORTANT]
> 1. **ツールの実行環境とUI（操作画面）のご希望**
>    以下のうち、どの形態が最も使いやすいでしょうか？
>    - **A) Web画面型 (Streamlitなど)**: ブラウザ上で画像をドラッグ＆ドロップすると、その場で数値が解析され、ExcelやCSVとしてダウンロードできる（Python環境があればローカルで簡単に起動でき、直感的でおすすめです）。
>    - **B) GUIアプリ型 (Tkinterなど)**: PC上で動作する専用のウィンドウアプリ。
>    - **C) コマンドライン実行型 (CUI)**: 特定のフォルダに画像を入れ、スクリプトを実行すると自動で一括処理される。
>
> 2. **出力先スプレッドシートの形式**
>    - **A) ローカルファイル形式**: Excelファイル（`.xlsx`）やCSVファイルとしてPC内に保存する。
>    - **B) Googleスプレッドシート直接書き込み**: API連携を用いて、クラウド上の指定スプレッドシートに直接行を追加する（※APIキーや認証設定が必要です）。
>
> 3. **読み取るべき項目（パラメータ）の範囲**
>    添付いただいた画像からは非常に多くの項目が読み取れます。スプレッドシートに記録したいのはどの範囲でしょうか？
>    - **A) 個別パラメータの数値のみ**（「決定力: 402」「ショートパス: 426」など17項目）
>    - **B) すべての項目**（選手名「Nico Williams」、ポジション「LW」、総合力「6739」、メインパラメータのランクと数値「SHO: D 1222」など、画面上のすべてのテキスト情報）
>    - **C) その他必要な項目のみ**（具体的に指定）
>
> 4. **画像処理の運用方法**
>    - 画像は1枚ずつその都度解析したいでしょうか？
>    - それとも、スマートフォンのスクリーンショットやPCのキャプチャをフォルダに貯めておき、複数枚を「一括で処理」したいでしょうか？

## 提案されるシステム構成案（技術選定）

ユーザーの動作環境（Windows PC）を想定し、Pythonをベースにした以下の構成を提案します。

1. **OCR（文字認識）エンジン**:
   - **候補1: EasyOCR (ローカル実行)**: 英語・日本語の認識精度が高く、オープンソースのため無料で動作します。
   - **候補2: Google Cloud Vision API / OpenAI Vision API (クラウド連携)**: 認識精度が極めて高く、レイアウトの崩れにも強いですが、少額 of API利用料とアカウント設定が必要です。
   - **候補3: OpenCV による事前画像処理 + Tesseract**: 画像の特定位置（ROI：関心領域）を切り出してOCRにかける手法。文字位置が常に固定されているゲーム画面には非常に有効で、認識精度を高められます。
2. **UIフレームワーク**:
   - **Streamlit**: 軽量かつ美しいWebインターフェースをPythonだけで構築可能で、画像のアップロードやテーブルプレビュー、Excelダウンロード機能が容易に実装できます。
3. **データ処理**:
   - **Pandas / Openpyxl**: 解析データを綺麗に表データ（DataFrame）として整理し、ExcelやCSVに変換します。
