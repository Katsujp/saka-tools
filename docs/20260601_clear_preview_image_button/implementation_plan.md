# プレビュー対象画像の個別クリアボタン追加計画

## 解決したい課題と背景
現在、読み込んだ画像をクリア（削除）する手段は、画面下部にある「解析結果テーブルを空にする」ボタンしかありません。
しかし、複数枚の画像をアップロードまたは貼り付けた後、特定の画像だけをプレビュー対象から取り除きたい（個別削除したい）というユースケースに対応していませんでした。
そこで、プレビュー対象画像のセレクトボックス（プルダウンメニュー）の直下に、選択中の画像をリストから個別に削除できる「画像をクリアする」ボタンを追加し、操作の快適性を向上させます。

---

## ユーザー確認事項（要レビュー）
> [!NOTE]
> **ボタンスタイリングと挙動について**
> 1. ボタンは、ユーザーが誤って押しやすいように、「選択中の画像をクリアする」という分かりやすい表示にし、横幅いっぱいにフィットさせます。
> 2. すべての画像がクリアされてリストが空になった場合、プログラムは自動的にプレビューHUDエリア自体を非表示にし、最初の画像ソースロード画面へとシームレスに差し戻します。

---

## 提案する具体的な変更内容

`app.py` における「プレビュー対象画像」セレクトボックスの直下にボタンを追加し、以下の削除ロジックを実装します。

### 1. 個別削除ロジックの実装
- 選択されている画像名（`selected_img_name`）をセッション状態 `st.session_state.target_images` から除外します。
- `st.success` で削除成功のインジケーターを一時的に表示させ、画面を安全に再起動（`st.rerun()`）します。

### 2. Apple Pro漆黒ミニマリズムスタイルの適用
- ボタンは Streamlit の `st.button` を用い、`use_container_width=True` を指定してセレクトボックスの横幅と完璧に調和させます。
- ボタン追加に伴う周辺レイアウトの調和（余白の調整など）を行います。

## 変更対象ファイル

### [MODIFY] [app.py](file:///d:/User%20Files/Masashi/HOME/repos/saka-tools/app.py)
- `selected_img_name = st.selectbox("プレビュー対象画像", img_names)` の直下に、以下の画像をクリアするボタンおよびその削除・再描画処理ロジックを追加します。

```python
    # 選択されている画像を取り除く削除処理
    if st.button("選択中の画像をクリアする", use_container_width=True):
        st.session_state.target_images = [
            (name, img) for name, img in st.session_state.target_images if name != selected_img_name
        ]
        st.success(f"画像「{selected_img_name}」をクリアしました。")
        time.sleep(0.5)
        st.rerun()
```
