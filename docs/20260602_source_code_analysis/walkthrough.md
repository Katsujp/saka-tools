# サカつく2026 パラメータOCRリーダー ソースコード解析レポート

本ドキュメントは、最新のソースコードを徹底解析し、システムの仕様、内部アーキテクチャ、およびプレミアムなUI/UX設計について詳細にまとめたレポートです。

---

## 1. システム概要
本プロジェクトは、サッカーシミュレーションゲーム「サカつく2026」の選手パラメータ画面のスクリーンショット画像から、選手の各種パラメータをOCR（光学文字認識）で自動抽出し、スプレッドシートや管理表へコピペしやすい形式でデータ化するStreamlitアプリケーションです。
独自の画像前処理アルゴリズムと、フロントエンドでのインタラクティブなアライメント調整Canvas HUDを融合することで、極めて高い認識精度と快適なUXを実現しています。

---

## 2. システムアーキテクチャ & モジュール構成

システムは以下の主要コンポーネントによって構成されています。

```mermaid
graph TD
    A[ユーザー画像入力] -->|ペースト/アップロード| B[app.py (Streamlit UI)]
    B -->|画像転送 & 状態同期| C[src/fitting_hud (Canvas HUD Component)]
    B -->|画像転送| D[src/paste_bridge (Paste Bridge Component)]
    C -->|アライメント・操作シグナル| B
    D -->|Base64画像データ| B
    B -->|アライメント座標 & 画像| E[src/ocr_engine.py (OCR Engine)]
    E -->|前処理 & EasyOCR| F[パラメータデータ抽出]
    F -->|Pandas DataFrame| B
    B -->|TSV展開| G[コピペステーション]
```

### ① ルート直下 [app.py](file:///d:/User%20Files/Masashi/HOME/repos/saka-tools/app.py)
プレミアムな「Apple Pro 漆黒ミニマリズムUI」を採用したメインの Streamlit アプリケーションです。
- クリップボードペースト (`paste_bridge`) やドラッグ＆ドロップによる画像ロードに対応。
- リアルタイムでアライメント（座標・スライダー調整）を行える `fitting_hud` を内包。
- 取得した画像はロード時にあらかじめ1920x1080サイズに自動トリミング・正規化されます。
- 解析結果はインタラクティブな `st.data_editor` で確認・手動微修正可能。
- `コピペステーション` 機能を備え、チェックボックス選択行のみを任意のフォーマットでコピペできます。

### ② [src/app.py](file:///d:/User%20Files/Masashi/HOME/repos/saka-tools/src/app.py)
Googleスプレッドシートへの直接自動追記機能や、Excelファイルダウンロード機能にフォーカスした以前のバージョンの Streamlit アプリケーションです。
- サービスアカウント認証（JSONファイル、貼り付け、キャッシュ）を用いて、指定のGoogleスプレッドシート（共有URLとシート名指定）の最終行へ解析結果を書き込みます。

### ③ [src/config.py](file:///d:/User%20Files/Masashi/HOME/repos/saka-tools/src/config.py)
ゲーム画面の基準解像度 (1920x1080) における各パラメータ枠（ROI: Region of Interest）の初期座標値や、項目名と日本語表示名のマッピングなどを定義する設定モジュールです。
- `DEFAULT_ROIS` に「総合力」「メイン数値」「個別詳細（FP項目）」のデフォルト座標（X, Y, W, H）を定義。
- `GROUPS` には、座標の一括調整（案A）を行うためのアライメント調整用グループ定義（カテゴリ別、ステータス系統別など）を保持。
- `GK_ALIASES` により、GKロール切り替え時に「タックル」→「セービング」、「パスカット」→「反応速度」、「マーク」→「1対1」の項目名へ動的に置換するマッピングを提供。

### ④ [src/ocr_engine.py](file:///d:/User%20Files/Masashi/HOME/repos/saka-tools/src/ocr_engine.py)
OpenCVを用いた高度な画像前処理と、EasyOCRを用いた文字・数値認識を行うコアエンジンです。
- **排他制御のスレッドロック**: マルチスレッド環境下（Streamlitの再描画など）でのCUDA（GPU）リソース競合やメモリクラッシュを100%防止する `self.lock = threading.Lock()` を実装。
- **専用モデル of 使い分け**: 数字の誤認識（日本語モデルとの干渉による「0」の消失など）を防ぐため、日本語モデル (`ja`, `en`) と数字/英数字専用モデル (`en`) の2つのEasyOCRリーダーを適切に使い分けています。

### ⑤ [src/paste_bridge](file:///d:/User%20Files/Masashi/HOME/repos/saka-tools/src/paste_bridge/index.html)
クリップボードからの画像直接貼り付け、ファイルのドラッグ＆ドロップ、およびモバイルデバイス（カメラ/長押しペースト）に対応した、HTML/JSベースの双方向 Streamlit カスタムコンポーネントです。
- 読み込んだ画像データをBase64形式のData URIに変換し、Streamlit側へ送信します。
- 重複ロードや無限 rerun を防ぐため、送信オブジェクトにランダムなワンタイムID（`id`）を付与して安全に状態管理を行っています。

### ⑥ [src/fitting_hud](file:///d:/User%20Files/Masashi/HOME/repos/saka-tools/src/fitting_hud/index.html)
ブラウザ上の Canvas 上にゲーム画面とアライメント枠線（ROI）を重ね合わせ、直感的に枠線の位置を調整できるHTML/JSベースの双方向カスタムコンポーネントです。
- スライダー操作（全体、グループ全体、個別パラメータ）による座標シフト（X, Y）やスケーリング（幅, 高さの縦横独立調整）をリアルタイムに反映。
- Python側のアライメント算出アルゴリズムをJS側に完全移植 (`calculateROI`) し、ミリ秒単位のゼロ遅延で Canvas を再描画します。
- 通信エラーや逆同期の競合（古い値での上書き戻り）を防止するガード機構を備えています。

## 3. 主要な機能仕様とアルゴリズムの解説

### ① 画像の外枠タイトルバー自動トリミング・正規化仕様
`SakatsukuOCREngine.scan_game_boundary` は、画像外周の輝度や色差の急激な変化を縦横スキャンし、ゲーム画面の正確な4辺の座標を1px単位で自動検出します。
1. **上部タイトルバー（0%〜15%）の検出**: Windows 11 のタイトルバーなどを検出し、境界Y座標を特定（デフォルト約31px）。
2. **左右・下部ウィンドウ枠の検出**: 左右約8px、下部約8pxのウィンドウボーダーを検出。
3. 検出された実際のゲーム表示領域そのものを切り出し、高品位なLanczos4補間 (`cv2.INTER_LANCZOS4`) を用いてアスペクト比を維持したまま `1920x1080` の基準解像度へリサイズ（正規化）します。これにより、ウィンドウ枠の有無や解像度の違い（ボケや歪み）を吸収し、基準ROI座標との完全なアライメント一致を実現します。

### ② 高精度アライメント座標（ROI）算出アルゴリズム
デフォルト座標に対して、ユーザーが調整した「グローバル」「グループ」「個別」の3レイヤーの調整値を積算適用して最終的なクロップ座標を決定します。
計算式は以下の通りです。
- **X座標**: `Math.round(デフォルトX + グローバルXオフセット + グループXオフセット + 個別Xオフセット)`
- **Y座標**: `Math.round(デフォルトY + グローバルYオフセット + グループYオフセット + 個別Yオフセット)`
- **幅 (Width)**: `Math.round(デフォルト幅 * グローバルXスケール * グループXスケール * 個別Xスケール)`
- **高さ (Height)**: `Math.round(デフォルト高さ * グローバルYスケール * グループYスケール * 個別Yスケール)`

このアライメント計算アルゴリズムは、フロントエンド (JS) とバックエンド (Python) で完全に一致しており、アライメント設定のJSONエクスポート・インポート機能により再現が可能です。

### ③ OCRの文字認識率を最大化する画像前処理アルゴリズム
OCRの読み取り精度を極限まで高めるため、クロップされた画像（特に小さな個別能力値など）に対して以下の前処理を適用しています。
1. **グレースケール化**: OpenCVでチャネル数を削減。
2. ** Lanczos4補間による3.5倍超拡大**: 画像のエッジを鮮明に保ち、余計なモヤモヤノイズを排除してEasyOCRの文字識別率を最大化します。
3. **ガウシアンブラー**: 拡大による細かな偽エッジノイズを平滑化。
4. **二値化**:
   - `総合力` などの主要な大文字: 生グレースケール拡大のまま、もしくは絶対閾値 `155` で二値化。
   - `カテゴリー数値`: 絶対閾値 `155` で二値化。
   - `個別能力値`: フォントが細く掠れやすいため、絶対閾値 `130` で二値化（または生グレースケール3.5倍拡大のみを適用して文字切れを防止）。
5. **白黒反転**: EasyOCRが最も得意とする「白背景に黒文字」に強制統一。

## 4. プレミアムなUI/UX設計の特色

本アプリケーションは、単なる業務ツールにとどまらない極めて高い完成度のプレミアムデザインが施されています。

### ① Apple Pro 漆黒ミニマリズムUI
- **カラースキーム**: 深みのあるダークグレー（`#1c1c1e`）をベースとし、カード型デザインに `#2c2c2e`、境界線に `#3a3a3c` を使用。フォントカラーには極めて上品な純白（`#ffffff`）と、システムセカンダリテキスト（`#8e8e93`）を用いてコントラストを最適化。
- **アクセントカラー**: Apple SF Pro Blue（`#0071e3`）をプライマリボタンやフォーカス枠線に採用し、うるさすぎないプロフェッショナルな統一感を演出。
- **スライダーのフォーカスハイライト**: HTML/JS側のスライダー部品は、キーボード操作やクリック時にフォーカスが当たると、つまみがより鮮やかな青（`#359aff`）に変化し、ネオン風のシャープなグロー効果（`box-shadow`）が適用されます。これにより、どのパラメータを調整しているかが一目で分かります。
- **チラつき防止**: Streamlitの再実行（rerun）に伴う画面全体のグレーアウトや一瞬のチラつきを防ぐため、透過度 `opacity: 1 !important` を強制適用するCSSハックが施されています。

### ② 画期的なコピペステーション
OCRで取得したパラメータデータを他システム（Googleスプレッドシートやローカルの管理表）に一瞬で転記できるよう、2つの展開モードを並列提供しています。
- **横展開TSV（スプレッドシート行追加用）**: カラムごとにタブ区切りで1行に並びます。スプレッドシートの空き行にそのままコピー＆ペースト可能です。
- **縦展開TSV（縦型カルテ入力用）**: 縦1列に項目名と値（または値のみ）が並びます。縦並びの管理表（カルテ形式）に一括流し込みできます。
- **項目名出力トグル**: チェックボックス一つで、項目ヘッダー（または選手画像名）を含めるか、値のみにするかをトグルできます。値のみを貼り付けたいユースケースに完全にフィットしています。

### ③ 双方向の安全ガード機構（逆流上書き戻り防止）
Streamlitのコンポーネント通信は非同期で行われるため、フロントエンド（JS）でスライダーを操作した直後に、バックエンド（Python）から以前の古いセッション情報が逆同期メッセージとして届き、スライダーの値が勝手に元に戻ってしまうバグ（競合状態）が発生しやすい性質があります。
本アプリでは、JS側で直前に送信した最新の状態を `lastSentState` としてディープコピーでキャッシュし、親から届くメッセージがこのキャッシュより古い、もしくは同一のアクションであるかを厳密に比較・判定することで、**逆流上書き戻りバグを構造的に100%封殺**しています。

## 5. まとめと今後の示唆
解析の結果、本アプリケーションは以下の点で極めて洗練されていることが確認できました。
- **画像の正規化の完全自動化**: ユーザーが手動で画面切り出しをする必要がない。
- **驚異的なOCR精度**: Lancetによる拡大・二値化の閾値チューニング、専用言語モデルの分離により、数字や記号の誤読が最小限に抑えられている。
- **ストレスのないリアルタイム調整**: フロントエンドにアライメント調整を移植することで、重いStreamlitサーバーを介さずブラウザ上で瞬時に枠線が描画される。
- **卓越したコピペステーション**: 管理者のコピペ転記作業のユースケース（縦並び・横並び）に完璧に応えている。

現在実装されているアライメント調整機能やOCR読み取り機能は完成度が非常に高く、今後のアップデート（サカつくシリーズのUI変更や新規パラメータ項目の追加など）に対しても、`src/config.py` ROI座標の更新やエイリアスの追加だけで柔軟に対応できる堅牢な設計になっています。
